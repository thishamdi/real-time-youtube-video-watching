# YouTube Watch Together

![YouTube Watch Together](api/assets/watch-youtube.png)

A real-time synchronized YouTube video watching platform that allows users to watch videos together in perfect sync. Create or join rooms and chat with other viewers while watching the same video simultaneously.

## Features

- 🎥 Real-time video synchronization across multiple users
- 💬 Live chat functionality with message history
- 🔄 Automatic state reconciliation and buffer handling
- 🎮 Synchronized player controls (play, pause, seek)
- 🔗 Easy room sharing with unique room IDs

## Tech Stack

### Frontend
- **Next.js 15** with App Router and TypeScript
- **TailwindCSS** for styling
- **Socket.IO Client** for real-time communication
- **React Player** for video playback
- **Custom YouTube Integration**

### Backend
- **Node.js** with Express
- **Socket.IO** for WebSocket connections
- **Supabase** for database and real-time features

## Architecture

The application follows a client-server architecture with real-time communication:

```
Client (Next.js) <---> WebSocket (Socket.IO) <---> Server (Node.js) <---> Database (Supabase)
```

### Real-time Synchronization

The synchronization system uses several mechanisms to ensure smooth playback:

- Buffer state tracking
- Throttled time updates
- Automatic seek reconciliation
- Ready state management
- Force sync on significant drift

## Key Components

### UnifiedVideoPlayer
- Handles video playback and synchronization
- Manages buffer states and ready events
- Implements YouTube player configuration
- Provides consistent player interface

### Socket Events
- Room management (create, join, leave)
- Video control synchronization
- Chat message handling
- State reconciliation
- Connection management

## Technical Challenges & Solutions

1. **Video Synchronization**
   - Challenge: Keeping multiple players in sync across network delays
   - Solution: Implemented threshold-based sync with buffer state management

2. **State Management**
   - Challenge: Handling complex player states across multiple clients
   - Solution: Centralized state management with server-side reconciliation

3. **Performance**
   - Challenge: Reducing unnecessary updates and network traffic
   - Solution: Throttled updates and optimized sync messages

4. **User Experience**
   - Challenge: Smooth playback during sync events
   - Solution: Buffer delay handling and progressive sync

  id bigint generated by default as identity primary key,

  message text not null,

);

## Getting Started

### Prerequisites
- Node.js >= 18
- npm or yarn
- Supabase account

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/youtube-watch-together.git
```

2. Install dependencies
```bash
# Frontend
cd client
npm install

# Backend
cd api
npm install
```

3. Set up environment variables
```bash
# Backend (.env)
PORT=5000
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key

# Frontend (.env.local)
NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
```

4. Run the application
```bash
# Backend
npm start

# Frontend
npm run dev
```
